# Everyday FSRS

Spaced repetition for everyday life, using the FSRS memory model.

**One-liner:** Anki-style recall for real life (names, passwords you insist on remembering, phrases) scheduled with the FSRS DSR model from peer-reviewed research.

## Research
Ye, J., Su, J., & Cao, Y. (2022). *A Stochastic Shortest Path Algorithm for Optimizing Spaced Repetition Scheduling*. Proceedings of KDD 2022. https://doi.org/10.1145/3534678.3539081 · https://www.maimemo.com/paper/

Open FSRS algorithm docs: https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm

### What is implemented vs inspired
- **Implemented:** FSRS-4.5 Difficulty / Stability / Retrievability update formulas and interval scheduling in the browser (default weights).
- **Not reproduced:** The paper’s SSP-MMC cost-optimization experiments and reported 12.6% online lift (those need large review logs / production traffic).
